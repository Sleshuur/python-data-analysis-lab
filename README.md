## Лабораторная работа №1 — Продвинутый NumPy

В работе рассмотрены:

- Точность чисел `float32` и `float64`, машинное эпсилон.
- Индексация, срезы и broadcasting.
- Memory-mapped файлы и скорость обхода массива.
- Разреженные матрицы CSR, COO и CSC.
- Сравнение скорости Python и Cython.

[Открыть лабораторную работу](labs/01_numpy/01_numpy.ipynb)

## Лабораторная работа №2 — NumPy и Pandas

- [Продолжение NumPy: задачи 6–8](labs/02_numpy_pandas/01_numpy_continued.ipynb)
- [Основы Pandas: задачи 1–6](labs/02_numpy_pandas/02_pandas_basics.ipynb)

Срезы и маски, большие массивы, сравнение производительности, разреженные матрицы. Работа с таблицами сотрудников: фильтрация, пропуски, группировка и объединение.

## Как запустить

Установить зависимости и открыть JupyterLab:

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```

Открыть нужный блокнот в папке `labs` и выполнить все ячейки по порядку.
Во второй лабораторной два независимых блокнота. Замеры NumPy используют до нескольких гигабайт памяти; дождитесь завершения всех ячеек.
Cython собирается из блокнота; для сборки нужен компилятор C.
Можно запустить работу в GitHub Codespaces — настройка окружения уже добавлена.
