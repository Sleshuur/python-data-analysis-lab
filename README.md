## Лабораторная работа №1 — Продвинутый NumPy

В работе рассмотрены:

- Точность чисел `float32` и `float64`, машинное эпсилон.
- Индексация, срезы и broadcasting.
- Memory-mapped файлы и скорость обхода массива.
- Разреженные матрицы CSR, COO и CSC.
- Сравнение скорости Python и Cython.

[Открыть лабораторную работу](labs/01_numpy/01_numpy.ipynb)

## Как запустить

Установить зависимости и открыть JupyterLab:

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```

Открыть `labs/01_numpy/01_numpy.ipynb` и выполнить все ячейки по порядку.
Cython собирается из блокнота; для сборки нужен компилятор C.
Можно запустить работу в GitHub Codespaces — настройка окружения уже добавлена.
